# python-learning

## Описание проекта
Этот репозиторий содержит мои учебные задачи по Python, выполненные в процессе подготовки к базовому уровню анализа данных и логическому программированию.
Задачи направлены на развитие навыков работы с:
- условиями (if)
- циклами (for)
- списками
- строками
- фильтрацией данных
- базовыми вычислениями (sum, max, min, average)

## Что я практиковала
- обработка строк и чисел
- фильтрация данных по условиям
- работа с циклами
- создание и изменение списков
- логические задачи с несколькими условиями
- базовые вычисления и агрегаты
  
## Структура репозитория
- 02_if_conditions.py — условия и логические проверки
- 03_loops.py — циклы for
- 04_lists.py — работа со списками
- 05_filtering.py — фильтрация данных
- 06_strings.py — комбинированные задачи
- 07_lists_basic.py — работа со строками
- 08_lists_filtering.py — сложные условия
- 09_lists_selection.py — тренировочные задачи
- 10_strings_lists.py — строки + списки
- 11_combined_logic.py — итоговые задачи

## Цель проекта
Закрепить базовые навыки Python и научиться решать логические задачи, похожие на тестовые задания для начальных позиций в аналитике и программировании.

## Статус
Проект находится в активной стадии обучения и регулярно дополняется новыми задачами.
